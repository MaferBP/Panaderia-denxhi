🚀 Próximos Pasos

Para poner en funcionamiento:

  1. Verificar MySQL está corriendo - Asegúrate que MySQL esté iniciado
  2. Inicia el Backend:
    cd backend
    python main.py
  3. En otra terminal, inicia el Frontend:
    cd frontend
    npm install
    npm run dev
  4. Abre el navegador: http://localhost:5173
  5. Prueba el flujo completo: Login → Inventario → Pedidos → Reportes
⚠️ Importante:
Si cambias el puerto del frontend, actualiza el CORS en backend/main.py
